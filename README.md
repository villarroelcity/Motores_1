# En el Camino

Motores de Desarrollo 1 – Unity - Parcial 1.

El jugador llega casi sin combustible a una estación de servicio rural abandonada. Para continuar con su viaje deberá explorar la estación de servicio y tratar de encender el generador para suministrar energía para poder hacer tratar de encender el surtidor de combustible. Una vez conseguido ello, deberá encontrar un bidón vacio para poder cargarlo de combustible ya que el auto quedo detenido.

## Controles

- `WASD` o flechas: mover al personaje.
- Mouse: orientar la cámara en tercera persona.
- `E`: interactuar con el generador y el surtidor.
- `Esc`: Salir del juego.

## Escena

La escena principal es `Assets/Scenes/EnElCamino.unity`. El prototipo usa controlador con `CharacterController`, cámara de seguimiento, Raycast, interacción, física, trigger de salida e instanciación de un prefab de combustible.

El edificio de la estación es un espacio cerrado con paredes y techo. El manejo completo y otras paradas del viaje quedan fuera del alcance de este primer prototipo.
